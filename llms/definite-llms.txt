## On-Prem

- [On-Prem](https://www.definite.app/docs/on-prem.md): Run Definite in your own cloud account.
- [Agent setup](https://www.definite.app/docs/on-prem/agent-setup.md): Point a coding agent (Claude Code, Cursor, Windsurf) at this page and it will walk a human through an on-prem Definite install end to end.
- [CLI](https://www.definite.app/docs/on-prem/cli.md): Install and use the `definite` CLI to operate and exercise an on-prem deployment.
- [Install on AWS](https://www.definite.app/docs/on-prem/aws.md): Stand up Definite in your own AWS account: EKS, RDS, S3, all driven by Terraform and the `definite` CLI.
- [Install on GCP](https://www.definite.app/docs/on-prem/gcp.md): Stand up Definite in your own GCP project: GKE, Cloud SQL Postgres, GCS, driven by `gcloud` and the `definite` CLI.
- [Install on Azure](https://www.definite.app/docs/on-prem/azure.md): Stand up Definite in your own Azure account: AKS, Azure Database for PostgreSQL, and Azure Blob Storage, driven by `az` and the `definite` CLI.
- [Google SSO](https://www.definite.app/docs/on-prem/sso.md): Sign in to your on-prem Definite deployment with Google Workspace via OIDC.
